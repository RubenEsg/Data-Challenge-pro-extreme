  Corrección: app/servicios/catalogos.py normaliza las columnas de texto de la tabla rutas (_texto) y

  «catalogo_no_disponible» (sin fuente) o «fuente_no_disponible» (réplica configurada pero caída, también antes de

  acepta un 503 solo si lleva el error uniforme con uno de esos códigos y la operación lo declara.
